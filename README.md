"By 2040, the ICT sector will contribute to 14% of the global carbon footprint. Software engineers are the architects of this future."
Sustain-Ability is an interactive simulation designed to teach the core principles of Sustainable Software Engineering (SSE). It challenges players to balance technical performance with environmental, social, and individual sustainability.

🎯 The Core Mission
Traditional Software Engineering focuses on Economic and Technical sustainability. This project expands that horizon by placing the engineer in a decision-making role focused on:

Environmental Sustainability (Green SE): Reducing energy consumption and carbon intensity.

Social Sustainability: Ensuring digital equity, accessibility, and global inclusion.

Individual Sustainability: Protecting developer mental health and user privacy.

🕹️ Simulation Features
Real-time Impact Metrics: Every decision updates a "Sustainability HUD" that tracks your performance across three pillars.

Phase-Based Logic: Experience the software lifecycle through Design, Build, and Release phases.

Green Logic Engine: Includes scenarios like "Carbon-Aware Scheduling" and "Energy-Efficient Language Selection" (e.g., Python vs. Rust).

Responsive Visuals: Built with a "Midnight Green" aesthetic to reflect the modern eco-tech landscape.

🏗️ Project Structure
The project is architected as a Single-File Interactive Application (SFA). This design choice itself follows sustainability principles: it requires zero build-tools, minimal server overhead, and fast loading times.

How the Logic Works:
State Management: Uses Vue's reactive ref system to track three metrics (Env, Soc, Ind).

Impact Matrix: Each decision option carries a "weight." For example:

Choosing Rust ➔ Environmental +20, Individual -10 (due to steep learning curve).

Feedback Loop: At the end of the simulation, a dynamic generator analyzes your scores to provide a professional SSE evaluation.

🚀 Quick Start & Deployment

1. Run Locally
Simply download the index.html file and open it in any modern web browser.

2. Deploy to GitHub Pages (Recommended)
Upload index.html to your GitHub Repository.

Go to Settings > Pages.

Under Build and deployment, set the branch to main.

Click Save. Your simulation will be live at:
